El trabajo consiste en la realización de una aplicación Android (Kotlin + Jetpack Compose).
La aplicación podrá realizarse en grupo (constituido por un máximo de tres personas).
Las características que debe cumplir OBLIGATORIAMENTE la aplicación son las siguientes:

Desarrollo en Kotlin
Uso de Jetpack Compose para la UI
Arquitectura MVVM
Uso de al menos un ViewModel
Gestión del estado mediante StateFlow
Navegación mediante Navigation Compose
La aplicación debe tener un mínimo de 2 pantallas
Mostrar al menos una lista utilizando LazyColumn
Uso de componentes Material3
Manejo de eventos de usuario (clicks, cambios de estado, etc.)
Internacionalizar la aplicación (al menos en Español e Inglés)
Calificación:

Aprobado: La ejecución de la aplicación deberá verificar el cumplimiento de todos los requisitos enunciados
Notable: Sólo se podrá optar a la calificación Notable si se ha superado la parte correspondiente al aprobado. Además, se deberá incluir:
Material3 Avanzado
Manejo adecuado y encapsulación avanzada del estado en Compose y Navigation
Diseño UI cuidado y consistente
Uso de Navigation Drawer o Bottom Navigation
Gestión de temas (claro/oscuro)
Uso de persistencia local (Room)
Implementación de una capa repository.
Sobresaliente: Sólo se podrá optar a la calificación Sobresaliente si se ha superado la parte correspondiente al notable. Además, la aplicación deberá incluir al menos cinco funcionalidades avanzadas adicionales, tales como:
CRUD completo de datos persistentes
Pantallas de detalle con navegación mediante múltiples parámetros
Uso de componentes modales
Gestión avanzada del estado
Formularios con validación de datos
Implementación de búsqueda o filtrado de datos
Uso de animaciones o transiciones de navegación
Viewmodel adicionales para separar responsabilidades
Arquitectura limpia y organización clara del proyecto
Interfaz moderna y consistente acorde con las guías oficiales de Android
Dependerá de la complejidad de la aplicación desarrollada
La obtención de la calificación de sobresaliente dependerá tanto del número de funcionalidades avanzadas implementadas como de la calidad del diseño, organización del código y experiencia de usuario de la aplicación.
